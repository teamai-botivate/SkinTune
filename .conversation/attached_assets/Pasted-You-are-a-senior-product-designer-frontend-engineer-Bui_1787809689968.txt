You are a senior product designer + frontend engineer.

Build a production-quality, mobile-first responsive frontend prototype for:

SKINTUNE — Personal Appearance Intelligence

IMPORTANT PRODUCT DIRECTION
----------------------------
SkinTune is NOT just a skin-tone detector.

The product understands:
- user's appearance profile
- skin tone and undertone
- body build and fit preference
- personal style
- colour preferences
- dislikes/restrictions
- occasion
- role
- venue
- time
- desired impression
- budget

Then it generates 5 personalized COMPLETE LOOK recommendations.

Each recommendation contains:
- outfit
- colours
- jewellery
- hairstyle
- makeup
- accessories

The final visual recommendations will eventually be generated using GPT Image 2.

IMPORTANT:
Do NOT build wardrobe digitisation/upload functionality in this version.
Do NOT build real-time wardrobe try-on.
The user will NOT upload their existing wardrobe.

The primary experience is:
USER PROFILE → CONTEXT → AI RECOMMENDATION → 5 COMPLETE LOOKS → USER FEEDBACK

Instead show a helpful diagnostic state.

Example:

"Let's try one more photo"

"Your skin tone confidence is currently low because the lighting is too warm."

Then:

"Try this:"
☀️ Move near a window
🚫 Turn off beauty filters
📱 Hold the phone at eye level
🙂 Keep your full face visible
⬜ Avoid strong shadows

CTA:
"📸 Retry Photo"

Secondary:
"Why does this matter?"

The retry screen should dynamically change depending on the detected problem.

Examples:

LOW LIGHT:
"Your photo is too dark. Move near natural daylight and avoid backlighting."

WARM LIGHT:
"The lighting is adding a warm tint. Try natural daylight without yellow indoor lights."

BLUR:
"The photo is slightly blurry. Hold your phone steady and take another photo."

ANGLE:
"Please face the camera directly so we can analyse your appearance more accurately."

FILTER:
"It looks like a beauty/filter effect may be affecting colour accuracy. Please upload an unfiltered photo."

FACE OCCLUDED:
"Please make sure your face is clearly visible without sunglasses, heavy obstruction or cropping."

NEEDS MULTIPLE RETRIES:
Allow retry and keep showing the exact improvement instruction.

After successful analysis:
Skin Tone
Undertone
Confidence

IMAGE GENERATION ARCHITECTURE
-----------------------------

Do NOT hardcode GPT Image 2 directly into UI components.

Create a service abstraction:

imageGenerationService

with a mock implementation initially.

Example conceptual structure:

generateLookImages(profile, context, recommendations)

The mock service should return 5 image URLs/placeholders.

Later the backend can replace this with the real GPT Image 2 API.

The frontend must not need to be rewritten when the real API is connected.


IMPORTANT:
The AI recommendation engine should decide WHAT the five looks are.

The image model should visualize those decisions.

Do not let the image model independently invent the user's styling strategy.

-------------------------------------

The eventual experience must translate naturally to WhatsApp.

Therefore:

1. Minimize free-text input.
2. Prefer selectable options.
3. Use emoji/symbol + text.

5. Avoid icon-only buttons.
6. Never rely on colour alone to communicate selection.
7. Use familiar symbols.
8. Keep option names short.

Good:

Good:
